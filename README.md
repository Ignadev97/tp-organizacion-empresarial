# TP Organización Empresarial

## Descripción

Proyecto colaborativo para el análisis de ventas simuladas utilizando Git, GitHub, Jira y Google Colab.

## Objetivo

Analizar un dataset de ventas comerciales y generar estadísticas básicas mediante scripts reproducibles en Python.

## Tecnologías utilizadas

* Python
* Pandas
* Git
* GitHub
* Jira
* Google Colab

## Estructura del proyecto

/scripts
Contiene scripts de análisis.

/datos
Contiene el dataset CSV.

/resultados
Contiene archivos generados por el análisis.
