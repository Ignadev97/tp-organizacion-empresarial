# TP Organización Empresarial

## Descripción

Proyecto colaborativo para el análisis de ventas simuladas utilizando Git, GitHub, Jira y Google Colab.

El proyecto fue desarrollado siguiendo una metodología de trabajo colaborativa basada en control de versiones y trazabilidad de tareas.

---

## Objetivo

Analizar un dataset de ventas comerciales y generar estadísticas básicas mediante scripts reproducibles en Python.

---

## Dataset utilizado

Dataset de ventas simuladas en formato CSV.

Contiene:
- fecha de venta,
- identificador de registro,
- monto de ventas.

---

## Tecnologías utilizadas

* Python
* Pandas
* Git
* GitHub
* Jira
* Google Colab

---

## Estructura del proyecto

### /scripts
Contiene los scripts de análisis de datos.

### /datos
Contiene el dataset CSV utilizado para el análisis.

### /resultados
Contiene archivos generados automáticamente por el script.

---

## Funcionalidades implementadas

El sistema realiza:

- lectura del dataset CSV,
- cálculo de total de ventas,
- promedio de ventas,
- valor máximo,
- valor mínimo,
- cantidad total de registros.

---

## Ejecución del proyecto

1. Clonar repositorio.
2. Abrir notebook en Google Colab.
3. Ejecutar el script:

```bash
python scripts/analisis_ventas.py
````

4. Revisar resultados en:

```text
/resultados/resumen_ventas.txt
```
